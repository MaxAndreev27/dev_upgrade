# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature for this repository, or contact the repository owner directly.

Include a clear description, steps to reproduce the issue, affected environment, and any proposed mitigation. You should receive an acknowledgment within 7 days.

## Scope

Reports are particularly useful when they concern command injection, unsafe privilege use, unintended execution of remote content, or exposure of secrets.
